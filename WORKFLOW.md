# Development Workflow Guide

## 📋 เมื่อไหร่ต้อง Run Script สร้าง Keys

### ✅ ต้อง Run ในกรณีเหล่านี้:

1. **เพิ่ม content ใหม่ใน Directus**
   - เพิ่ม translation key ใหม่
   - เพิ่มภาษาใหม่

2. **แก้ไข fallback text**
   - เปลี่ยน default text ใน Directus
   - แก้ไขข้อความ fallback

3. **ลบ content ใน Directus**
   - ลบ key ที่ไม่ใช้แล้ว

4. **Deploy version ใหม่**
   - ก่อน build production
   - ก่อน commit code

### ❌ ไม่ต้อง Run ในกรณีเหล่านี้:

- แก้ไข translation value เฉพาะภาษา (ไม่แก้ fallback)
- เปลี่ยน status draft/published
- แก้ไขโค้ด Dart ใน app

## 🚀 วิธีการ Run Script

### วิธีที่ 1: ใช้ Dart Command (แนะนำ)

```bash
cd packages/directus_i18n
dart run example/generate_keys.dart
```

### วิธีที่ 2: ใช้ Makefile (สะดวกที่สุด)

```bash
cd packages/directus_i18n
make sync-keys
```

### วิธีที่ 3: ใช้ VSCode Task

1. กด `Cmd+Shift+P` (Mac) หรือ `Ctrl+Shift+P` (Windows/Linux)
2. พิมพ์: `Tasks: Run Task`
3. เลือก: `Generate I18n Keys from Directus`

### วิธีที่ 4: ใช้ Watch Mode (Auto Sync)

```bash
make watch-keys
# จะ sync ทุก 60 วินาที
```

## 🔄 Workflow แนะนำ

### สำหรับ Content Team

```bash
# 1. เพิ่ม content ใน Directus CMS
# 2. Run sync command
make sync-keys

# 3. Commit generated file
git add lib/generated/i18n_keys.dart
git commit -m "chore: sync i18n keys from Directus"
```

### สำหรับ Development Team

```bash
# 1. Pull latest code
git pull

# 2. Sync keys (ทำครั้งแรกหรือเมื่อมีการเปลี่ยนแปลง)
make sync-keys

# 3. Develop & Test
flutter run
flutter test
```

### สำหรับ CI/CD Pipeline

```yaml
# .github/workflows/build.yml
steps:
  - name: Sync I18n Keys
    run: |
      cd packages/directus_i18n
      dart run example/generate_keys.dart
  
  - name: Verify Keys Updated
    run: |
      git diff --exit-code lib/generated/i18n_keys.dart
      # Fail if keys are out of sync
```

## 📝 Best Practices

### 1. ใช้ Git Hooks (แนะนำ)

สร้างไฟล์ `.git/hooks/pre-commit`:

```bash
#!/bin/sh
# Auto-sync i18n keys before commit

echo "🔄 Checking i18n keys..."
cd packages/directus_i18n
dart run example/generate_keys.dart

# Add generated file to staging
git add lib/generated/i18n_keys.dart

echo "✅ I18n keys synced!"
```

```bash
chmod +x .git/hooks/pre-commit
```

### 2. Schedule Regular Sync

เพิ่มใน crontab (สำหรับ local development):

```bash
# Sync every day at 9 AM
0 9 * * * cd /path/to/project/packages/directus_i18n && make sync-keys
```

### 3. Create npm/yarn Script

ถ้าใช้ npm ใน project:

```json
// package.json
{
  "scripts": {
    "i18n:sync": "cd packages/directus_i18n && dart run example/generate_keys.dart",
    "i18n:watch": "cd packages/directus_i18n && make watch-keys"
  }
}
```

## 🔧 Configuration

### Environment Variables

สร้าง `.env` file:

```bash
DIRECTUS_BASE_URL=https://your-directus.com
DIRECTUS_ACCESS_TOKEN=your-token
I18N_OUTPUT_PATH=lib/generated/i18n_keys.dart
I18N_ENUM_NAME=I18nKeys
```

แล้วแก้ `example/generate_keys.dart`:

```dart
import 'package:flutter_dotenv/flutter_dotenv.dart';

Future<void> main() async {
  await dotenv.load();
  
  await DirectusI18nKeyGenerator.generate(
    baseUrl: dotenv.env['DIRECTUS_BASE_URL']!,
    accessToken: dotenv.env['DIRECTUS_ACCESS_TOKEN']!,
    outputPath: dotenv.env['I18N_OUTPUT_PATH'] ?? 'lib/generated/i18n_keys.dart',
    enumName: dotenv.env['I18N_ENUM_NAME'] ?? 'I18nKeys',
  );
}
```

## 📊 Automation Options

### Option 1: GitHub Actions (Recommended)

```yaml
name: Sync I18n Keys

on:
  schedule:
    - cron: '0 0 * * *'  # Daily at midnight
  workflow_dispatch:      # Manual trigger

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: subosito/flutter-action@v2
      
      - name: Sync Keys
        run: |
          cd packages/directus_i18n
          dart run example/generate_keys.dart
      
      - name: Create Pull Request
        uses: peter-evans/create-pull-request@v5
        with:
          title: 'chore: sync i18n keys from Directus'
          body: 'Auto-generated by GitHub Actions'
          branch: 'sync-i18n-keys'
```

### Option 2: Webhook from Directus

Setup Directus webhook to trigger sync when content changes:

```javascript
// Directus Hook
export default {
  'items.create': () => triggerCISync(),
  'items.update': () => triggerCISync(),
  'items.delete': () => triggerCISync(),
};
```

### Option 3: Local File Watcher

```bash
# Install fswatch (Mac)
brew install fswatch

# Watch Directus changes (if you have local Directus)
fswatch -o /path/to/directus/data | xargs -n1 -I{} make sync-keys
```

## 💡 Tips & Tricks

1. **Cache Generated Keys**: Commit `i18n_keys.dart` to version control
2. **Diff Check**: Review generated file before commit
3. **Backup**: Keep backup of Directus before major changes
4. **Dry Run**: Test script with `--dry-run` flag (if implemented)
5. **Notifications**: Add Slack/Discord notification after sync

## ❓ FAQ

**Q: จะรู้ได้ไหมว่า keys ไม่ sync?**
A: ใช้ CI check:
```bash
dart run example/generate_keys.dart --verify
# Returns exit code 1 if out of sync
```

**Q: Sync ล้มเหลวทำไง?**
A: 
1. ตรวจสอบ Directus connection
2. ตรวจสอบ access token
3. ดู error logs
4. ลอง manual sync

**Q: ต้อง sync ทุก environment ไหม?**
A: ไม่ต้อง - sync ครั้งเดียว แล้ว commit file ที่ generate ได้

**Q: Multi-project ต้องทำยังไง?**
A: แยก output path:
```dart
// Project A
outputPath: 'lib/generated/i18n_keys_project_a.dart'

// Project B
outputPath: 'lib/generated/i18n_keys_project_b.dart'
```
